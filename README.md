Spatial SHAP: King County Housing Experiment
The repository contains the Python code and experimental results for comparing Standard SHAP ad KNN-based Spatial SHAP using the King County housing dataset.
Files:

King_publication.py – Main Python code

publication_results/ – Figures and CSV results

experiment_notes.md – Experiment notes and key findings

kc_house_data.csv – Dataset

Current status: Experiments completed; results under discussion.
